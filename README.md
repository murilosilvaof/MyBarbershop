# MyBarbershop

Site single page para uma barbearia premium, com layout dark, servicos, equipe e fluxo de agendamento online.

## Funcionalidades

- Layout responsivo com Tailwind CSS via CDN
- Agendamento em etapas
- Escolha de servico, barbeiro, data e horario
- Dados do cliente e pagamento simulado via Pix ou cartao
- Mensagem de WhatsApp para aceite do barbeiro
- Estados de horario livre, aguardando e ocupado

## Como rodar

Abra o arquivo `index.html` diretamente no navegador.
